# intention refiner
this is a agent that reads a text in a file it's identifying 

## What it does
* **Reads your intention**: The agent reads a file that contains software requirements.
* **Finds requirements**: It identifies project goals, user needs, and required features.
* **Detects missing information**: It finds gaps, unclear points, and missing details in your text.
* **Provides suggestions**: It gives recommendations to fill those missing gaps.
* **Organizes the data**: It sorts all information into a clean, standard structure.
* **Saves a clear report**: It writes the final requirements and recommendations into an organized file for your team.

## Architecture

`intention refiner` follows a **hexagonal (ports and adapters) architecture**.
